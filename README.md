# Компьютер простыми словами (Готово для деплоя на Vercel)

Интерактивный обучающий сайт для полных новичков без сторонних зависимостей.

## 🚀 Как загрузить этот проект на Vercel

### Вариант 1: Через Vercel CLI (самый быстрый, в одну команду)
1. Откройте терминал в этой папке.
2. Выполните команду:
   ```bash
   npx vercel
   ```
3. Следуйте подсказкам в терминале (войдите в аккаунт, нажмите Enter на всех вопросах по умолчанию).
4. Через 15 секунд вы получите готовую публичную ссылку вида `https://computer-for-beginners-...vercel.app`!

---

### Вариант 2: Через GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите файлы из этой папки (`index.html`, `vercel.json`, `package.json`, `.gitignore`).
3. Зайдите на [vercel.com](https://vercel.com) ➔ нажмите **Add New...** ➔ **Project**.
4. Выберите ваш репозиторий и нажмите **Deploy**.

---

### Структура папки
- `index.html` — Полный автономный сайт (HTML + CSS + SVG + JavaScript внутри).
- `vercel.json` — Конфигурация маршрутизации для Vercel.
- `package.json` — Метаданные проекта.
- `.gitignore` — Исключение лишних временных файлов.
